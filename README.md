# Catalogue Mascofo — GitHub Pages

Cette version contient **2519 notices** provenant de `Mascofo.xlsx`.

## Recherche

- Titre
- Auteur (champ source : `Mentions de responsabilité`)
- Cycle (liste déroulante)
- Discipline (liste déroulante)
- Date de début
- Date de fin

## Affichage des notices

- Cycle : pastille rouge cliquable
- Titre : grand texte noir
- Auteur : lien cliquable
- Autres métadonnées : collection, éditeur, date, date d'autorisation, édition, format, ISBN/ISSN, lieu, niveau et notes
- Langue : pastille rouge cliquable
- Discipline : pastille grise cliquable

Les valeurs séparées par `|` sont traitées comme plusieurs valeurs distinctes.

## Publication sur GitHub Pages

1. Créez un dépôt public, par exemple `mascofo`.
2. Téléversez `index.html`, `style.css`, `script.js`, `data.csv` et `README.md` à la racine.
3. Ouvrez **Settings → Pages**.
4. Choisissez **Deploy from a branch**.
5. Sélectionnez `main` puis `/ (root)`.
6. Enregistrez.
